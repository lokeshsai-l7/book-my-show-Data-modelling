# 🎬 BookMyShow Database Design

## 📌 Brief

BookMyShow is a movie ticket booking platform where users can:

- Select a theatre
- View the next 7 available dates
- Choose a specific date
- View all movies running in that theatre
- View show timings for each movie
- Book tickets

This project focuses on designing a normalized relational database schema and writing SQL queries to support this functionality.
